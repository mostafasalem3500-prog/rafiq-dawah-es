# رفيق الداعية · Compañero del da'i

موقع يساعد الداعية، مهما كانت خبرته، على دعوة الناطقين بالإسبانية إلى الإسلام. يقدّم رسائل قصيرة وقوالب محادثات ومنهجًا متدرجًا بالإسبانية مع المعنى العربي والنطق الصوتي. ويجلب الآيات والأحاديث والكتب **كما هي** من مصادر موثوقة، على منهج أهل السنة والجماعة.

## ما الذي يقدمه؟

| **قوالب المحادثات** | 15 حوارًا نموذجية بإرشاد للداعية عند كل خطوة. |

| **أفكار وسلاسل** | 14 فكرة دعوية عملية، و5 سلاسل رسائل يومية جاهزة لأنواع المحاورين. |

| **دليل الداعية والتحذيرات** | إرشادات بالعربية، و15 تحذيرًا من المواضيع والأخطاء التي تُخسر الباحث عن الحقيقة. |

| **البحث** | بحث بالعربية والإسبانية في كل المحتوى. |

## الالتزام بالمصادر

- الآيات من **QuranEnc.com** (ترجمة محمد عيسى غارسيا وترجمتا مركز نور الدولي) مع اسم الترجمة ورقم إصدارها، دون أي تعديل.
- الأحاديث من **HadeethEnc.com** بنصها الإسباني والعربي ودرجتها وتخريجها، دون أي تعديل.
- الكتب والمقالات والمرئيات من **IslamHouse.com** بروابطها الأصلية.
- الرسائل والمقالات القصيرة والقوالب نصوص مستقلة أُعدّت بالاستعانة بمواد هذه المصادر، وليست إصدارًا منها، وفق سياسة الاستخدام في [IslamHouse API Hub](https://github.com/IslamHouse-API/multilingual-quran-hadith-islamic-content-database-api-hub). وتحتاج اعتماد مراجع علمي قبل اعتمادها رسميًا.
- الموقع لا يولّد نصوصًا دينية بالذكاء الاصطناعي. ترجمة Gemini أداة مساعدة لفهم رسائل المحاور وصياغة ردود الداعية، وتُوسَم في الواجهة بأنها ترجمة آلية تُراجع قبل الإرسال، وتعليماتها تمنع ترجمة الآيات وتحيل إلى الترجمة المعتمدة.

## ترتيب طبقات الصوت والذكاء الاصطناعي

| الترتيب | الصوت (`/api/tts`) | النص: الترجمة والمعلّم |
|---|---|---|
| 1 | المقطع المحفوظ (ذاكرة ثم قرص): فوري ومجاني | النتيجة المحفوظة 7 أيام |
| 2 | **Gemini TTS**: أجود الأصوات وهو الأساسي | **Gemini** |
| 3 | **أصوات مفتوحة المصدر** على الخادم: [Kokoro-82M](https://github.com/hexgrad/kokoro) للإسبانية (دورا، أليكس، سانتا) و[Piper](https://github.com/rhasspy/piper) «كريم» للعربية، عبر [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx). يُشكَّل النص العربي قبل نطقه بـ DeepSeek (ثم Gemini)، ويُرفض التشكيل إن تغيّر أي حرف | **DeepSeek** |
| 4 | يعيد المتصفح المحاولة تلقائيًّا | رابط Google Translate |

- DeepSeek نصّي فقط لا يولّد صوتًا؛ دوره في الصوت تشكيل العربية للصوت المفتوح.
- يظهر المحرك الذي ولّد كل مقطع في الترويسة `X-TTS-Engine` (`gemini` أو `kokoro` أو `piper+tashkeel`). وحالة الأصوات المفتوحة في `/api/tts/voices`.
- آيات القرآن (النص بين ﴿ ﴾) لا يقرؤها الصوت المفتوح أبدًا؛ التلاوة من قراء EveryAyah.
- اختبار ذهاب وإياب عبر Whisper large-v3-turbo (5 نوفمبر 2026): خطأ الكلمات 0–1.7% بالإسبانية، و12.8% بالعربية بعد التشكيل مقابل 28.8% بدونه. لذلك يبقى Gemini الصوت العربي الأساسي.
- السرعة على معالجين: Kokoro نحو 0.9× زمن المقطع، وPiper نحو 0.06×. ويحمّل المتصفح الجملة التالية أثناء تشغيل الحالية.
- **الرخص:** sherpa-onnx وKokoro برخصة Apache-2.0. وصوت Piper العربي «كريم» دُرّب على بيانات لغير الاستخدام التجاري (انظر `models/vits-piper-ar_JO-kareem-medium/MODEL_CARD`)، وهذا مناسب لموقع دعوي مجاني.
- النماذج (نحو 235MB) **لا تُرفع إلى المستودع**. يحمّلها `scripts/fetch-voices.js` من إصدارات sherpa-onnx على GitHub تلقائيًّا بعد `npm install`، فتدخل في صورة Railway عند البناء. وإن فشل التحميل لا يفشل البناء، بل يعيد الخادم المحاولة في الخلفية.
- `sherpa-onnx-node` مثبّت على **1.12.40**، لأن الإصدار 2 حذف مرحلة النطق المدمجة (espeak-ng) فلا يقرأ الإسبانية ولا العربية.

## التشغيل

```bash
npm install        # يحمّل الأصوات المفتوحة أيضًا (تخطَّه بـ SKIP_OPEN_VOICES=1)
npm start          # http://localhost:3000
npm run check      # يتحقق من أرقام الآيات والمعرّفات، ومن بيانات الدورة والتصريف
npm run fetch-voices   # إعادة تحميل الأصوات المفتوحة يدويًّا
```

المتغيرات الاختيارية:

| المتغير | الوظيفة |
|---|---|
| `GEMINI_API_KEY` | مفتاح Google AI Studio لتفعيل المترجم. يُضاف في Railway ← الخدمة ← Variables، ولا يُكتب في الكود. |
| `GEMINI_MODEL` | نموذج الترجمة (الافتراضي `gemini-flash-latest`). |
| `TRANSLATE_DAILY_LIMIT` | حد الترجمات اليومي للموقع كله (الافتراضي 300) لحماية رصيد المفتاح. |
| `ISLAMHOUSE_API_KEY` | المفتاح العام المنشور في توثيق IslamHouse مضمّن افتراضيًا. |
| `DEEPSEEK_API_KEY` | احتياطي Gemini في الترجمة والمعلّم، ومشكِّل النص العربي للصوت المفتوح. |
| `OPEN_TTS_THREADS` | عدد أنوية المعالج للأصوات المفتوحة (الافتراضي: عدد الأنوية حتى 4). |
| `OPEN_TTS_QUEUE` | أقصى عدد مقاطع تنتظر في الطابور لكل لغة (الافتراضي 24). |
| `TASHKEEL_DAILY_LIMIT` | حد طلبات التشكيل اليومية (الافتراضي 1500). |
| `OPEN_TTS_DIR` | مجلد النماذج (الافتراضي `models/`). |
| `SKIP_OPEN_VOICES` | `1` لتخطي تحميل النماذج عند التثبيت. |
| `PORT` | منفذ الخادم. |

## تعديل المحتوى

المحتوى كله في `public/data-core.js` و`public/data-long.js`. لكل عنصر مراجع: `q` (سورة:آية) و`h` (رقم الحديث في HadeethEnc). شغّل `npm run check` بعد أي تعديل.
