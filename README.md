# رفيق الداعية · Compañero del da'i

موقع يساعد الداعية، مهما كانت خبرته، على دعوة الناطقين بالإسبانية إلى الإسلام. يقدّم رسائل قصيرة وقوالب محادثات ومنهجًا متدرجًا بالإسبانية مع المعنى العربي والنطق الصوتي. ويجلب الآيات والأحاديث والكتب **كما هي** من مصادر موثوقة، على منهج أهل السنة والجماعة.

## ما الذي يقدمه؟

| القسم | الوظيفة |
|---|---|
| **المُركِّب** | يختار الداعية نوع المحاور ومرحلته وموقفه والقناة وخبرته، فيحصل على خطة ورسالة وقالب محادثة ومقالة ولقاء من المنهج وتحذيرات. |
| **حلّل رسالة المحاور** | يلصق الداعية رسالة المحاور بالإسبانية، فيكشف الموقع موضوعها ويقترح الرد والقالب والمزالق. يعمل في المتصفح ولا يرسل النص لأي جهة. |
| **الرسائل القصيرة** | 36 رسالة بالإسبانية مع معناها العربي، مرتبطة بآيات وأحاديث. |
| **قوالب المحادثات** | 9 حوارات نموذجية بإرشاد للداعية عند كل خطوة. |
| **مقالات قصيرة** | 12 مقالة من ثلاث فقرات مع خلاصة عربية. |
| **المنهج** | «Descubre el islam en 12 encuentros»: منهج متدرج من سؤال الغاية إلى الشهادتين. |
| **المكتبة** | آيات QuranEnc، وأحاديث HadeethEnc، وكتب IslamHouse الإسبانية ومقالاتها ومرئياتها. |
| **النطق** | نطق إسباني بأكثر من لهجة (حسب أصوات الجهاز)، مع التحكم في السرعة وطبقة الصوت، وقراءة جملة جملة، وعبارات يحتاجها الداعية. |
| **دليل الداعية والتحذيرات** | إرشادات بالعربية، و15 تحذيرًا من المواضيع والأخطاء التي تُخسر الباحث عن الحقيقة. |
| **البحث** | بحث بالعربية والإسبانية في كل المحتوى. |

## الالتزام بالمصادر

- الآيات من **QuranEnc.com** (ترجمة محمد عيسى غارسيا وترجمتا مركز نور الدولي) مع اسم الترجمة ورقم إصدارها، دون أي تعديل.
- الأحاديث من **HadeethEnc.com** بنصها الإسباني والعربي ودرجتها وتخريجها، دون أي تعديل.
- الكتب والمقالات والمرئيات من **IslamHouse.com** بروابطها الأصلية.
- الرسائل والمقالات القصيرة والقوالب نصوص مستقلة أُعدّت بالاستعانة بمواد هذه المصادر، وليست إصدارًا منها، وفق سياسة الاستخدام في [IslamHouse API Hub](https://github.com/IslamHouse-API/multilingual-quran-hadith-islamic-content-database-api-hub). وتحتاج اعتماد مراجع علمي قبل اعتمادها رسميًا.
- الموقع لا يولّد نصوصًا دينية بالذكاء الاصطناعي.

## التشغيل

```bash
npm install
npm start          # http://localhost:3000
npm run check      # يتحقق من صحة أرقام الآيات والمعرّفات في المحتوى
```

المتغيرات الاختيارية: `PORT`، و`ISLAMHOUSE_API_KEY` (المفتاح العام المنشور في توثيق IslamHouse مضمّن افتراضيًا).

## البنية

```
server.js            خادم Express ووسيط مُخزِّن للمصادر الثلاثة
public/index.html    الواجهة (عربية RTL، والمحتوى الإسباني LTR)
public/app.js        المنطق: المُركِّب، التحليل، النطق، المكتبة، البحث
public/data-core.js  الرسائل، التحذيرات، الكشف، الخطط
public/data-long.js  المقالات، القوالب، المنهج، دليل الداعية
scripts/check-data.js التحقق من المحتوى
```

## تعديل المحتوى

المحتوى كله في `public/data-core.js` و`public/data-long.js`. لكل عنصر مراجع: `q` (سورة:آية) و`h` (رقم الحديث في HadeethEnc). شغّل `npm run check` بعد أي تعديل.
